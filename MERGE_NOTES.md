# Combined version

Based on silent-explorers-v8 from Downloads, combined with the local version developed in this chat.

Preserved from v8: six-slide presentations for each of six missions, gathering orbit cards, full-screen reading, pinned word-reveal introduction, and surface-duration chart.

Preserved from this chat: locally bundled planetary maps and credits, three texture detail levels, high-DPI rendering, cached artwork, visibility-aware rendering, and paced solar-system scrolling.

Integration fixes: shared measurement API, idle animation settling, pause/reduced-motion support across sections, cancellation of intro scrolling on navigation, accessible hidden cards and slides, and a visible full-screen reading button. Neither input project was changed.

Open dist/index.html in Chrome with its sibling files in place.
